## Quality Toolchain

The precommit task now runs:
1. compile - Syntax and correctness
2. deps.unlock --unused - Dependency cleanup
3. format --check-formatted - Code style
4. credo --min-priority high - Static analysis
5. dialyzer - Type checking (zero tolerance)
6. test - Full test suite

## Philosophy

- Zero tolerance: Type errors, test failures, formatting issues
- Advisory: Style warnings, function grouping preferences
- Pragmatic: Maintainability over strict style conformance

## Breaking Changes

None. All existing functionality preserved.

## Migration Notes

Developers should:
1. Run `mix deps.get` to install dialyxir
2. Run `mix dialyzer --plt` to build PLT (one-time, ~1 minute)
3. Use `mix precommit` before committing
